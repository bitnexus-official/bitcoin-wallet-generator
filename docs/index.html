이 브라우저에서는 지갑을 만들 수 없습니다 카카오톡 안에서 열린 화면입니다. 이 상태에서 지갑 정보를 저장하면 파일이 대화방으로 전송되어 카카오 서버에 그대로 남을 수 있습니다. 오른쪽 위 메뉴에서 다른 브라우저로 열기를 선택한 뒤 다시 시도해 주세요.
개인지갑 생성 전 안내
  1. 데이터 미보관
    회사는 지갑 생성 과정에서 생성·표시되는 모든 정보를 어떠한 방식으로도 저장·수집·전송·백업하지 않습니다. 따라서 이용자가 해당 정보를 분실하거나 훼손한 경우 회사도 복구할 수 없습니다.
  2. 이용자 책임
    지갑의 생성·보관·사용·백업 및 접근 통제는 이용자가 직접 관리합니다. 이용자의 과실로 인한 손해에 대하여 회사는 책임을 부담하지 않습니다.
  3. 안전한 환경 권고
    지갑 생성 전에 악성코드 감염, 루팅/탈옥, 원격제어 앱, 화면 녹화/캡처, 키로거 등이 없는 신뢰 가능한 기기·네트워크에서 실행해야 합니다.
  4. 무상 제공 기능
    이 기능은 제품 이용의 편의를 위해 무상으로 제공되며, 회사는 지갑 관리나 자산 보관 서비스를 제공하지 않습니다.
  5. 웹 지갑의 한계
    이 기능으로 생성된 지갑은 웹 브라우저에서 만들어지므로 하드웨어 지갑만큼 안전하지 않습니다. 보관 금액이 커질 경우 하드웨어 지갑 등 더 안전한 지갑으로 옮기시기 바라며, 장기 보관용으로는 적합하지 않습니다.
⚠️ 경고 아래 정보는 보안을 위해 단 한 번만 표시됩니다. 반드시 파일로 저장해 두세요. 하단의 [지갑 정보 저장] 버튼을 클릭하면 지갑 정보가 포함된 파일 다운로드가 시작됩니다. 사용 환경에 따라 버튼 클릭 후 "저장" 또는 "다운로드"를 추가로 클릭해야 할 수 있습니다.파일(bitcoin_wallet_*.txt)이 정상적으로 저장되었는지 반드시 확인해 주세요. 해당 정보 또는 파일을 분실할 경우 지갑에 접근할 수 없습니다.

※ 저장되는 파일은 실행 코드가 없는 단순 텍스트(.txt) 파일로, 파일 자체에 악성코드가 포함되어 있지 않습니다. 다만 니모닉과 비밀키가 암호화되지 않은 상태로 그대로 저장되므로 파일 보관에 각별히 주의해 주세요.

※ 다운로드 폴더가 iCloud·구글 드라이브 등에 자동 동기화되고 있다면 동기화 대상에서 제외해 주세요. 또한 이 파일을 메신저나 이메일로 보내지 마세요. 전송하는 순간 해당 서비스 서버에 파일 내용이 그대로 남습니다.
